# 知航题库 · GitHub Pages 部署包

此包只包含网站运行文件和 100 道原创模拟单选题，不包含考生成绩单、报名信息、个人附件、托管凭据或原平台的站点配置。

## 部署

1. 将压缩包解压后的文件上传到 GitHub 仓库根目录。`index.html` 应直接位于根目录，不要再套一层文件夹。
2. 保留 `.nojekyll` 文件。
3. 在仓库 Settings → Pages 中，选择 Deploy from a branch；选择 main 分支、根目录 `/ (root)`，保存。
4. 以 Pages 设置中实际返回的网站地址为准，不要将仓库地址当成答题地址。
5. 部署完成后，用手机关闭 VPN，分别在移动网络和常用 Wi-Fi 下测试打开、答题、刷新和分享；部署成功不等于所有网络都能正常访问。

GitHub Free 的 Pages 需要公开仓库。公开仓库的程序及题库文件可以被其他人查看或下载。GitHub Pro 等支持的方案可从私有仓库发布网站，但网页本身仍按公开链接访问。

## 答题功能

- 单选点选即判，下方立即显示参考答案、解析与相关官方资料链接。
- 顺序、专项、随机与限时练习；错题本与收藏。
- 本轮选项一经点选不可修改；重练答对自动移出错题本。
- 进度保存在当前浏览器，不跨设备同步。换托管地址后，原地址的浏览器记录不会自动迁移。
- 无需账号或密码，没有外部运行时依赖。
- 已设置 noindex 与 robots.txt 请求不被搜索引擎收录；这不是访问控制，也不能保证网址绝不被索引。

这是原创模拟练习，不是官方历年真题，也不代表本岗位官方考试大纲。
